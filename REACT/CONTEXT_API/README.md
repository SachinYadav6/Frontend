# ⚛️ React Context API Example

A simple React project demonstrating how to use **Context API** for sharing data between components without passing props manually.

## 🚀 Features

- Uses React Context API
- Shares data between components
- Uses `createContext`
- Uses `useContext` hook

## 🛠️ Technologies Used

- React JS
- JavaScript (ES6)

## ⚙️ How It Works

Context API creates a global data store that can be accessed by multiple components.

In this project:
- `createContext()` creates a context
- `Provider` sends data to components
- `useContext()` receives the data inside child components
