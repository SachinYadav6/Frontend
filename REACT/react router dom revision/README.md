# React Router DOM Demo

A simple React application demonstrating basic routing using React Router DOM.

## Features

- Home Page
- About Page
- Contact Page
- Navigation between pages
- Clean and responsive layout

## Technologies Used

- React
- React Router DOM
- CSS
- Vite

## Installation

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Project Structure

```
src
├── pages
│   ├── Home.jsx
│   ├── About.jsx
│   └── Contact.jsx
├── App.jsx
├── main.jsx
└── index.css
```

## Learning Outcome

- Configure React Router
- Create multiple routes
- Navigate between pages
- Organize components into separate pages
