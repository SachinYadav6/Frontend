# 🐱 Random Cat Image App

A simple React app that fetches a random cat image from The Cat API and displays it on the screen.

## 🚀 Features

- Fetch random cat images using API
- Uses React useEffect for API calls
- Uses React useState to store image URL
- Displays cat image dynamically

## 🛠️ Technologies Used

- React JS
- JavaScript
- The Cat API

## 📦 API Used

https://api.thecatapi.com/v1/images/search

## ⚙️ How It Works

The app fetches a random cat image from The Cat API using fetch().  
The image URL is stored in React state and displayed on the webpage.

## ▶️ Run Project

npm install

npm run dev
