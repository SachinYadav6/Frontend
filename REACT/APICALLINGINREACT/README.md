# React Image Gallery using API 🖼️

A simple React JS project that fetches images from the Picsum Photos API and displays them in a beautiful card layout. This project demonstrates API integration, React state management, props handling, and reusable components.

## 🚀 Features

- Fetch images from Picsum Photos API
- Display dynamic image cards
- Reusable Card component
- Show image author name
- Manage API data using React `useState`
- Render multiple cards using JavaScript `map()`
- Pass data using React props
- Responsive card design


## 🛠️ Technologies Used

- React JS
- JavaScript (ES6)
- CSS
- Fetch API


## 🔗 API Integration

This project uses **Picsum Photos API** to fetch images.
