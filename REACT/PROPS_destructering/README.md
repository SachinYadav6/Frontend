# React Props Practice

A React practice project focused on understanding and implementing **Props, Destructuring, Objects, Arrays, and Functions as Props**.

## 🚀 Concepts Covered

* Props passing from Parent → Child
* Props Destructuring
* Object Props
* Array Props
* Function as Props
* Calling a function received through props
* Getting and displaying a function's return value
* `useState` for updating UI

## 📌 Examples

### Object Props

```jsx
user={{ name: "Sachin", age: 25 }}
```

### Array Props

```jsx
skills={["HTML", "JAVASCRIPT", "JAVA", "REACT"]}
```

### Function as Props

```jsx
girl={girlName}
```

Child component:

```jsx
const value = girl();
setgilname(value);
```

## 🛠️ Technologies

* React
* JavaScript
* JSX
* Vite

## 🎯 Learning Goal

The main goal of this project is to understand how data and functions are passed between React components using **Props**, instead of memorizing syntax.
