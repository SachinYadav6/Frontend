# React Todo App 📝

A simple Todo App built with **React** and styled using **Bootstrap**.  
This project demonstrates basic CRUD operations (Create, Read, Update, Delete) in React.

---

## 🚀 Features
- ➕ Add new tasks
- 🗑️ Delete tasks
- ✏️ Update existing tasks
- 🎨 Styled with Bootstrap for clean UI

---

## 🛠️ Tech Stack
- **React** (Functional Components + Hooks)
- **Bootstrap 5** (for styling)
